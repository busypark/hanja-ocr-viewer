# POC: 네이버 한자 OCR API 테스트

네이버 한자 OCR API의 요청 포맷과 응답 구조를 탐색하기 위한 단독 프로토타입.  
Express 서버 없이 브라우저에서 직접 `fetch()`로 API를 호출하고 결과를 콘솔에서 확인한다.

## 목적

- 획 좌표를 URL 인코딩 포맷(`%3DR%20...`)으로 압축하는 방식 탐색
- API 응답 구조(`{ content: "한자,설명;한자,설명;..." }`) 확인
- CORS 제한 확인 → **서버 프록시 방식 필요** 결론 도출

## 파일

| 파일 | 설명 |
|------|------|
| `ocr-test.html` | 캔버스 그리기 + OCR API 직접 호출 + 콘솔 출력 |

## 실행

브라우저에서 `ocr-test.html`을 직접 열거나 로컬 서버로 서빙.  
결과는 브라우저 콘솔(F12 → Console 탭)에서 확인.

> CORS 오류 발생 → 브라우저에서 직접 외부 API 호출 불가 확인.  
> 이 한계로 인해 이후 Express 서버 프록시 방식으로 전환.
